# Zero to First Commit

### My First GitHub Commit — ZTFC Workshop

This repository was created as part of a **Zero to First Commit (ZTFC)** workshop to practice the fundamentals of Git and GitHub.

The project contains a simple Markdown file with a first message and serves as a beginner-friendly record of getting started with version control and GitHub.

## 📌 About


## 🚀 Basic Git Workflow

A typical workflow for making the first commit looks like this:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <repository-url>
git push -u origin main
```

## 📖 What Is a Commit?

A **commit** is a saved snapshot of changes in a Git repository.

For example:

```text
Working Files
     |
     v
   git add
     |
     v
Staging Area
     |
     v
 git commit
     |
     v
Git History
```

Each commit provides a point in the project's version history and normally includes a message describing the change.
